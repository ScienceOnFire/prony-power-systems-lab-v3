# Prony Power Systems Lab V3
Run npm install and npm run dev, or import this folder into StackBlitz. Vercel preset: Vite, build npm run build, output dist.
CSV: time in seconds followed by uniformly sampled numeric channels (Hz deviations); optional header. The simulator is a linearized swing-equation benchmark, not Nordic 32. Classical and multichannel least-squares linear prediction use SVD pseudoinverse; SVD mode uses stronger truncation. Pencil uses a shifted Hankel least-squares operator (full-order, not a separately rank-selected matrix pencil). Oscillatory poles only; DC and real poles omitted. Phase similarity is exploratory, not automatic validated clustering. Sliding windows use nearest-frequency matching. No live PMU connection. No validation against commercial tools.
